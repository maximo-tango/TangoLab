# Maximo Tango Lab

아르헨티나 탱고 수업을 더 잘 준비하고, 연습을 더 체계적으로 이어가도록 돕는 정적 웹페이지입니다.

수업 일정, 음악 감상, 연습 루틴, 커플 평가를 한 곳에서 볼 수 있도록 구성되어 있어 강습 전후 흐름을 자연스럽게 이어갈 수 있습니다. 강사와 학생이 함께 참고하기 좋은 형태로, 수업 현장에서도 바로 사용할 수 있게 만들었습니다.

## 이 페이지는

- 수업 일정을 한눈에 확인할 수 있고
- 음악과 리듬을 함께 살펴볼 수 있고
- 반복 연습을 정리하고 기록할 수 있으며
- KTC 대회 준비 과정과 커플별 평가를 관리할 수 있습니다.

## 주요 구성

- 수업 캘린더: 강습 일정과 수업 흐름을 확인
- Music Lab: 음악 감상과 파형을 이용한 구조 이해
- Practice Lab: 회차별 연습 루틴과 타이머
- Rhythm Lab: 박자 감각 훈련
- KTC 대회준비반: 커리큘럼과 체크리스트
- 커플 평가: 점수 입력, 저장, 추이 확인

## 커플 평가 권한

평가 조회는 링크가 있는 사용자에게 읽기 권한이 부여된 Google 스프레드시트에서 데이터를 가져오므로 Google 로그인이 필요하지 않습니다. 평가 저장은 시트 편집 권한을 가진 Google 계정으로 로그인해야 합니다.

주의: 스프레드시트를 링크 보유자에게 공개하면 UI에서 선택 커플만 보여주더라도 해당 문서의 모든 탭과 데이터가 링크를 아는 사람에게 읽힐 수 있습니다. 학생별 접근 제한이 필요하면 공개 권한 대신 인증된 조회 방식을 사용해야 합니다.

이 페이지는 기능 중심 설명이 아니라, 탱고 수업을 더 잘 따라가고 준비하는 데 초점을 두는 공간입니다. 수업과 연습, 평가를 연결해 보면서 탱고 학습의 흐름을 더 자연스럽게 이어가도록 구성했습니다.
